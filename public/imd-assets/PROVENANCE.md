# IMD reference assets

Source: https://imd.fun/
Retrieved for a local visual prototype at the user's explicit request.

Files:
- `desk.webp` — IMD desk/floor scene
- `pepe.webp` — IMD green character sprite sheet
- `crew.webp` — IMD seated operator sprite sheet
- `chair.webp` — chair layer
- `dog.webp` — dog sprite sheet
- `wall-original.png` — rendered capture of the public IMD machine-wall canvas
- `wall-blue.png` — local color adaptation that changes green machine indicators to blue
