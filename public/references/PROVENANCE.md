# Original visual references

All 21 active selector images in this folder were generated specifically for Personality.md on 2026-10-05 with OpenAI image generation

They are original alternatives inspired only by the general interaction pattern of visual character builders

They do not copy or reuse images from Higgsfield or any other third-party studio

Groups

- `build-1.webp` through `build-7.webp` — full-body front-facing adult figures regenerated from the user supplied proportions direction with heads hands and shoes fitted inside each card
- `hair-1.webp` through `hair-7.webp` — regenerated from the user supplied hairstyle direction as seven original sculptural fashion wigs
- `heritage-1.webp` through `heritage-7.webp` — consistent front-facing bust portraits regenerated from the user supplied selector direction with full heads and shoulders fitted inside each card

Each group is deliberately limited to seven options
